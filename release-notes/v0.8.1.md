## Upgrade

Run the installer again:

```bash
curl -fsSL https://github.com/l7aromeo/user-memory/releases/latest/download/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://github.com/l7aromeo/user-memory/releases/latest/download/install.ps1 | iex
```

- The store keeps its format, so nothing is migrated and nothing needs your
  input.
- Codex's hooks are unchanged, so Codex needs no new approval.
- On Windows, a Docker install that stopped with
  ``… is already in use; stop what listens there, or pass --port``
  on a port nothing listens on works now: run the installer again.

## Fixed

- Windows: `install.ps1 -Local docker` no longer refuses every port as
  already in use. On Windows a free port refuses a connection only after
  about two seconds, which the installer's port check took for a listener.
  It now tries to take the port first, and counts it as in use only when
  that fails because the port is taken, or when something answers on it
  ([#1](https://github.com/l7aromeo/user-memory/issues/1)).
