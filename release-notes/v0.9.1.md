## Upgrade

Run the installer again:

```bash
curl -fsSL https://github.com/l7aromeo/user-memory/releases/latest/download/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://github.com/l7aromeo/user-memory/releases/latest/download/install.ps1 | iex
```

- The store keeps its format (schema version 6), so nothing is migrated
  and nothing needs your input.
- The installer's Docker server is rebuilt with the new release, as for
  every upgrade.
- Codex's hooks are unchanged, so Codex needs no new approval.

## Fixed

- rustls 0.23.46 fixes an advisory that let a network attacker make later
  TLS connections from user-memory, to the embeddings endpoint, a remote
  memory server or doctor's release check, use only classical key
  exchange, without post-quantum protection
  ([GHSA-w44r-93j7-qv28](https://github.com/advisories/GHSA-w44r-93j7-qv28)).
  The same release fixes three more advisories that don't affect
  user-memory, which never formats a TLS session and uses neither Brotli
  certificate decompression nor ECH (GHSA-c8m5-c952-6cm4,
  GHSA-h2v8-394m-p7vv, GHSA-vp88-798v-h67f).
