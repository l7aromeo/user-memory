## New

<!-- VERIFY: the other new items -->
- **Export or import one checkout's memories by folder.** On the command
  line, `user-memory export` and `import` take `--project .` (or another
  folder) as `read` does, naming that checkout's project.
- **Import says what to do next, when there is something.** After an
  applied import, the summary's `next` suggests review when imported
  memories resemble stored ones, and an optional reindex when memories were
  added; on a client of a server it names where reindex runs. A preview no
  longer has one.
- **A missing export lists the ones there are.** Asked for an export name
  that is not in the exports directory, the import tool lists the newest
  names there, so an agent can ask which one the user means.
